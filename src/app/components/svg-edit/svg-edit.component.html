How to Use the SVG Editor

✏️ Drawing

  • Use the freehand tool to draw new lines.

  • Click on a line to move it.

🗑️ Deleting

  • Double-click a line to remove it.

  • Use the Erase tool to delete lines.

🔄 Undo, Redo & Reload

  • Click "Undo" to revert changes.

  • Click "Redo" to redo a reverted action.

  • Click "Reload SVG" to restore the original image.

🔢 Adding Isoline Values

  • Click anywhere on the SVG to add a number (only one per session).

  • Choose a value and direction from the input fields.

🖱️ Moving Lines

  • Click on any line to drag and reposition it.

💾 Saving & Uploading

  • Click "Download" to save your edited SVG file.

  • Click "Upload" to send your SVG to the server.
