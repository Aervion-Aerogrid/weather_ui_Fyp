Instructions

  • Select an image type from the dropdown.

  • Use the tools to edit, add, or delete isolines.

  • Click "Download" to save your SVG file.

  • Click "Upload" to send it to the server.

  • Click Undo/Redo to get back changes.

  • One click on any line to drag it.

  • Use the freehand draw to draw lines.

  • Use Erase to delete lines or double click a line.

  • Reload SVG to get the initial image.
